# Threshold Boolean Networks in Plasmodium falciparum

This repository contains codes and analyses for the inference of Threshold Boolean Networks (tBNs) applied to the intraerythrocytic developmental cycle (IEC) of *Plasmodium falciparum*.

## Objectives

- Build functional modules from temporal transcriptomic data
- Infer threshold Boolean regulatory networks
- Analyze attractors and state transition dynamics
- Investigate synchronization mechanisms in parasite populations

## Repository structure

```text
src/              -> source codes
data/raw/         -> original datasets
data/processed/   -> processed datasets
results/          -> figures and inferred networks
notebooks/        -> exploratory analyses
manuscript/       -> LaTeX files
```

## Datasets

- Bozdech et al. (2003)
- Otto et al. (2010)
- Subudhi et al.
- Broadbent et al.
